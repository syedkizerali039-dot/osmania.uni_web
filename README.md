A Django-based web application for looking up and displaying student examination results using a hall ticket number.
Features
- Displays available result records on the home page.
- Accepts a student's hall ticket number for a marks lookup.
- Retrieves and displays student details, including name, father's name, hall ticket number, and gender.
- Displays marks for six subjects and calculates the total in the results template.
- Shows an error page when no matching hall ticket number is found.
- Provides a print button on the marks page.
Tech Stack
- Backend: Python, Django
- Frontend: HTML, CSS, Django Templates
- Database: SQLite (the repository includes db.sqlite3; confirm the configured database in settings.py)
